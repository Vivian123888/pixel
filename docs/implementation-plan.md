# PIXEL Hub — Plano de Implementação

## Entrega atual — núcleo operacional
- Dashboard ligado ao PostgreSQL.
- Projetos com cadastro e listagem.
- Tarefas com cadastro, prazo, prioridade e conclusão.
- Diretório de pessoas com papéis e estado da conta.
- Calendário com cadastro de reuniões, prazos, eventos e treinamentos.
- Layout responsivo para desktop e mobile.
- Rotas do núcleo protegidas por sessão.
- Migration versionada para eventos.

## Próximas fases
1. Permissões granulares verificadas no servidor e gestão de pessoas.
2. Comentários, anexos, aprovações e notificações.
3. Governança, Pesquisa, Extensão, Produtos e PIXEL Sports.
4. Gamificação, PWA, segurança operacional, acessibilidade e testes E2E.

Os códigos internos de processos ficam restritos à documentação e auditoria técnica; a interface deve priorizar o trabalho real do grupo.
